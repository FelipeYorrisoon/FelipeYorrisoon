I focus on binary analysis, digital forensics, and threat research, with a strong foundation in software development and computer networking.

Rather than simply interpreting Assembly instructions, I focus on understanding the intent behind the code, execution flow, and the techniques used to compromise environments — and documenting that with technical precision.

## 🔍 What I focus on

**Malware Analysis & Reverse Engineering**
- Static and dynamic analysis of binaries
- Execution chain reconstruction and evasion technique identification
- YARA rule development and behavioral mapping
- Adversary technique mapping via MITRE ATT&CK

**Digital Forensics & Incident Reconstruction**
- Process injection, DLL injection, and process hollowing analysis
- Covert communication and C2 infrastructure identification
- Malicious code documentation with technical precision
- Incident timeline and evidence reconstruction

**Deep Technical Analysis**
- Toolkit: Ghidra, x64dbg, REMnux, FLARE VM, Volatility
- Development background: Java, C/C++, Python, Assembly
- Legacy system and codebase risk quantification
- Trust boundary mapping across systems and networks
